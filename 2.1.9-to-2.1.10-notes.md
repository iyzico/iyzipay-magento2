# iyzipay for Magento — Notes (2.1.9 → 2.1.10)

## Yeni Özellikler

### Display Type Konfigürasyonu
- Ödeme yöntemi için yeni display type (görüntüleme tipi) konfigürasyonu eklendi
- Admin panelden **Redirect** veya **iFrame** seçeneği arasında seçim yapılabilir
- Yeni `DisplayType` source model eklendi (`Model/Config/Source/DisplayType.php`)
- `ConfigHelper`'a `getDisplayType()` metodu eklendi

### iFrame Desteği
- Ödeme formu artık iFrame içinde gösterilebilir
- Payment method renderer iFrame desteği için geliştirildi
- JavaScript renderer'da iFrame ve redirect modları için ayrı işlem mantığı eklendi

## Geliştirmeler

### Controller Güncellemeleri
- `IyzipayRequest` controller'ı farklı display type'ları destekleyecek şekilde güncellendi
- Response data'ya `displayType` bilgisi eklendi
- Display type'a göre uygun response formatı döndürülüyor

### Helper Güncellemeleri
- `ConfigHelper` güncellendi - display type konfigürasyonu desteği eklendi
- `ObjectHelper` ve `UtilityHelper` metodları yeni display type mantığıyla uyumlu hale getirildi

### Hata Yönetimi ve Logging
- Ödeme süreçlerinde hata yönetimi iyileştirildi
- Logging mekanizması geliştirildi

## Teknik Değişiklikler

### Yeni Dosyalar
- `Model/Config/Source/DisplayType.php` - Display type seçenekleri için source model

## Kullanım

Admin panelden **Stores > Configuration > Sales > Payment Methods > iyzico** bölümüne giderek **Display Type** seçeneğinden ödeme formunun nasıl gösterileceğini seçebilirsiniz:
- **Redirect**: Kullanıcı iyzico sayfasına yönlendirilir (varsayılan)
- **iFrame**: Ödeme formu mevcut sayfada iFrame içinde gösterilir
